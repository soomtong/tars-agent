# MCP 통합과 컨텍스트 비용

## MCP 클라이언트 (후속 단계)

MCP 도구는 호스트 함수의 한 종류일 뿐이다. 서버가 광고한 도구마다 Cyber 선언을 생성해 mcp 네임스페이스 아래에 노출한다. 입력 스키마는 Cyber 타입으로 낮춘다. 낮출 수 없는 스키마(재귀, 복잡한 oneOf)는 JSON 문자열 인자로 받는 일반 호출 함수로 폴백한다.

- 전송은 stdio 우선, HTTP는 후속
- tools/list 수집, tools/call 호출, isError와 structuredContent 처리
- annotations(readOnlyHint, destructiveHint)는 신뢰하지 않는 서버에서는 참고만 한다
- list_changed 는 턴 사이에 반영한다
- 권한 게이트와 절단은 내장 함수와 동일하게 적용한다

## 컨텍스트 비용

- 코드 실행 방식이 기본 절감이다: 중간 결과는 스크립트 안에서 줄이고 필요한 것만 출력한다. 사양에 이를 지시한다.
- 지연 로딩: 핵심 함수 사양만 프롬프트에 싣고 나머지는 help()로 조회한다.
- 결과 압축: 컴팩션 때 오래된 출력을 요약으로 치환한다.
- 호스트 함수 결과 크기 통계를 모아 최적화 근거로 쓴다 (07).
- 프롬프트 캐싱: 시스템 프롬프트와 함수 사양을 앞쪽에 고정하고 순서를 안정적으로 유지한다.
