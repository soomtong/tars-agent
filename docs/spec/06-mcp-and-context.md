# MCP 통합과 컨텍스트 비용

## MCP 클라이언트

MCP 도구는 실행 함수가 원격 호출인 도구일 뿐이다. 레지스트리, 스키마, 절단, 권한은 내장 도구와 동일하게 적용한다.

- 전송: stdio 우선, HTTP는 후속
- tools/list로 정의 수집, tools/call로 호출
- isError와 structuredContent 처리
- annotations(readOnlyHint, destructiveHint 등)를 권한 분류에 사용. 신뢰하지 않는 서버의 힌트는 참고만 한다
- list_changed 알림은 턴 사이에 반영
- 진행 알림과 취소 지원
- 엘리시테이션은 승인 UI와 같은 경로로 처리 (후속)

## 컨텍스트 비용 관리

- 지연 로딩: 핵심 도구만 노출, 나머지는 tool search 도구로 찾아 그때 정의 로드
- 결과 압축: 컴팩션 때 오래된 결과를 요약으로 치환
- 도구 수 제한: 비슷한 도구는 합치거나 설명에서 경계 명시
- 도구별 결과 크기 통계를 수집해 최적화 근거로 쓴다 (07 문서)
- 프롬프트 캐싱: 시스템 프롬프트와 도구 정의를 앞쪽에 고정해 캐시 적중률을 높인다. 도구 목록 순서를 안정적으로 유지한다
