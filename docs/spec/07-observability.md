# 관측

## 세션 로그

- 형식: JSON Lines, 세션당 파일 하나
- 기록 항목: 타임스탬프, 도구 이름, 인자(마스킹 후), 결과 크기, 소요 시간, is_error, 권한 판단 결과
- 모델 호출: 모델 이름, 입력/출력 토큰, 캐시 토큰, 지연
- 위치: 사용자 상태 디렉터리 (XDG 규칙, 확인 필요)

## 추적

- 호출마다 span을 만들고 서브에이전트까지 한 트리로 연결 (후속)
- OpenTelemetry 내보내기는 선택 기능

## 통계

- 도구별 평균/최대 결과 크기, 오류율, 평균 소요 시간
- 세션 종료 시 요약 출력 옵션

## 재현

- 세션 로그로 히스토리를 복원해 재개(resume)할 수 있어야 한다
