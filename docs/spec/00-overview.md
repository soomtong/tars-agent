# 개요

## 목표

- tars-linux 위에서 동작하는 터미널 기반 AI 에이전트를 Cyber 언어로 구현한다.
- 모델이 세계와 접촉하는 유일한 통로인 도구를 안전하고 예측 가능하게 운영하는 하네스를 만든다.
- 스킬이나 별도 학습 문서 주입 없이, 도구 정의와 도구 결과만으로 모델이 올바르게 동작하게 한다.

## 비목표

- GUI, 웹 프런트엔드 (초기 범위 밖)
- 자체 모델 학습 또는 호스팅
- 다중 사용자 서버 운영
- 대화형 TTY 프로그램(vim, less 등) 직접 지원

## 대상 환경

- OS: tars-linux. 배포판의 패키지 관리, init, libc, 커널 버전은 미확정이며 확인이 필요하다 (TODO P0).
- 구현 언어: Cyber. 런타임 배포 방식과 FFI 가능 범위는 08 문서 참고.
- 모델 제공자: 우선 Anthropic Messages API. 어댑터 계층으로 다른 제공자를 추가할 수 있게 한다.

## 사용 시나리오

1. 사용자가 터미널에서 자연어로 작업을 요청한다 (예: 로그 분석, 설정 파일 수정, 서비스 점검).
2. 에이전트가 읽기 도구로 상태를 파악하고, 편집/셸 도구로 변경을 제안하고 실행한다.
3. 위험 작업은 권한 게이트에서 사용자 승인을 받는다.
4. 헤드리스 모드(스크립트, cron)에서는 사전 정의된 정책만으로 동작한다.

## 용어

- 하네스: 모델 호출, 도구 실행, 권한, 로그를 담당하는 프로그램 전체
- 도구: 이름 + JSON 인자를 받아 텍스트 또는 이미지 결과를 돌려주는 실행 단위
- 턴: 모델 호출 한 번과 그에 따른 도구 실행 묶음
- 세션: 하나의 대화 히스토리와 관련 로그
- 권한 게이트: 도구 실행 직전의 정책 계층
