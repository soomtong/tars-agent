# 개요

## 목표

- tars-linux 안에서 동작하는 내장 AI 코딩 에이전트 tars-agent를 만든다. 본보기는 Claude Code다: 터미널에서 돌고, 소수의 잘 다듬은 도구와 권한 게이트, 세션 기록, 프로젝트 지시 파일을 가진다.
- 다른 점은 실행 모델이다. 에이전트는 도구 호출을 JSON으로 나열하지 않고 Cyber 스크립트를 써서 실행한다 (CodeAct). 도구는 호스트가 Cyber 함수로 열어 준 능력(capability)이다.
- 모델이 세계와 접촉하는 통로를 하네스가 안전하고 예측 가능하게 운영한다. 실패는 모두 결과로 돌아가고, 권한 판단은 코어에 둔다.
- 모델이 보는 것은 시스템 프롬프트(규칙, Cyber 부분집합 안내, 능력 사양, 환경 정보), 프로젝트 지시 파일(AGENTS.md), 대화와 실행 결과다.

## 세 가지 기준

이 명세의 모든 항목은 아래 셋으로 걸렀다.

- 현대적: 2026년의 에이전트 하네스가 기본으로 갖는 것(스트리밍, 프롬프트 캐싱, 적응형 사고, 컴팩션, 세션 재개, 프로젝트 지시 파일, 권한 규칙, OS 샌드박스)을 빠뜨리지 않는다.
- 믿을 만함: 보안 경계를 문서로 설명할 수 있고, 측정(평가 과제, 게이트)으로 주장한다. 깨지기 쉬운 장치(셸 문자열 파서에 기댄 안전 판정 등)에 안전을 맡기지 않는다.
- 만들 수 있음: 한 사람이 단계마다 동작하는 것을 손에 쥔다. v1은 프로세스 하나, 세션 하나, 의존은 Zig 표준 라이브러리와 libcyber뿐이다.

## v1 범위

- 실행 파일 하나: tars-agent. 대화형(REPL)과 헤드리스(-p) 두 모드.
- 능력: 파일 읽기/검색/편집, 프로세스 실행, HTTP 가져오기, 질문, 할 일 목록, 메모.
- 권한: 모드 다섯, 규칙 파일, 승인 프롬프트, 실행 프로세스의 Landlock 샌드박스.
- 세션: JSONL 기록, 재개, 컴팩션.
- 모델 제공자: Anthropic Messages API 하나.

## 비목표

- 다중 사용자 서버 운영
- GUI와 GUI 승인 창. 화면은 tars terminal이 그린다

## 대상 환경 (확인된 사실)

출처: soomtong/tars-linux 0.2.0, soomtong/cyber(fork) master 63e35e88 (0.4.10-DEV). 확인일 2026-11-10, cyber는 2026-11-14.

- tars-linux는 직접 빌드한 Linux 커널(6.18) 위에 Zig로 만든 init(PID 1)과 터미널(DRM/KMS + ghostty-vt)을 올리고 fish로 간다. 배포판이 아니다.
- 대상 아키텍처는 x86_64만이다. 개발 호스트는 Apple Silicon macOS이고 빌드는 컨테이너 안에서 한다. tars-agent는 macOS에서도 빌드되고 돌아야 한다 (개발과 평가를 호스트에서 한다). 샌드박스만 Linux 전용이다.
- 바닥 라이브러리는 Debian glibc다. 개별 도구는 sha256을 고정한 미리 빌드 바이너리로 개발 도구 층(devlayer)에 들인다. devlayer에 cyber CLI 번들(기준 빌드보다 옛 판. tars-agent는 CLI를 쓰지 않는다), ripgrep, fd, jq가 이미 있다.
- 터미널은 워크스페이스 아홉 × 패널 여덟을 가진다. 외부 프로세스가 패널을 조작하는 제어 채널은 없다. 에이전트는 패널 하나 안에서 도는 보통 프로그램이다.
- 커널에 CONFIG_SECCOMP가 없다. Landlock 설정 여부는 확인이 필요하다 (TODO M5).
- 부팅은 네트워크 유무와 무관하게 평소대로 끝나야 한다 (tars 결정). 에이전트는 부팅 경로에 없다. 사용자가 명령으로 실행한다.
- Cyber는 fubark/cyber의 fork다. upstream은 2025-12 이후 멈췄고 fork가 Zig 0.17.1, 임베딩 API, 중단/연료(fuel)/스택/메모리 상한을 직접 유지한다 (08).

## 문서 규약

- 문서와 주석에 강조용 ** 를 쓰지 않는다. 코드 블록 펜스는 ~~~ 를 쓴다.
- 커밋 메시지는 접두사 없이 첫 글자 대문자, 80자 이내.
- 새 결정은 docs/decisions에 파일로 남기고 MEMORY.md에 한 줄만 추가한다.
- 외부 의존은 docs/deps.md에 이유와 라이선스를 적는다. GPL 계열은 들이지 않는다.

## 용어

- 하네스: 모델 호출, 스크립트 실행, 권한, 기록을 담당하는 프로그램 전체. 실행 파일 이름은 tars-agent
- 능력: 하네스가 Cyber 스크립트에 열어 주는 호스트 함수. 이 프로젝트에서 도구의 실체다
- run: API 수준의 유일한 도구. Cyber 소스를 받는다
- 턴: 사용자 입력 하나에서 모델이 도구 호출 없이 답할 때까지의 묶음. 그 안의 모델 호출 한 번은 스텝
- 세션: 대화 히스토리 하나, Cyber VM 하나, 기록 파일 하나
- 프로파일: 세션이 시작할 때 정해지는 능력 집합. 모드: 세션 안에서 바뀌는 승인 정책 (05)
- agentd: 여러 세션을 맡는 데몬의 이름. v1에는 없다 (ADR 0004)
