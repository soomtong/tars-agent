# 도구 시스템

도구 하나의 생애: 정의 - 선택 - 실행 - 결과. 모델은 정의와 결과만 본다.

## 정의 필드

- name: 짧은 동사형. 외부 도구는 mcp__서버__도구 네임스페이스
- description: 언제 쓰고 언제 쓰지 않는지, 결과 모양, 상한, 전제와 부작용
- input_schema: JSON Schema
- examples (선택): 입력 예 한두 개
- annotations (선택): readOnly, destructive, idempotent, openWorld
- defer_loading (선택): 검색 시에만 노출

정의는 매 모델 호출마다 전송되므로 토큰 비용이 있다. 도구 수와 설명 길이를 예산으로 관리한다.

## 레지스트리

- 등록 출처: 내장, 플러그인, MCP
- 이름 충돌은 등록 시 오류. 네임스페이스로 회피
- 활성 집합은 모드(계획 모드 = 읽기 전용만)와 에이전트 정의로 결정
- 목록 변경(MCP list_changed)은 턴 사이에만 반영

## 스키마 처리

- 입력 검증: 실패 시 실행하지 않고 원인을 담은 오류 결과를 반환
- 오류 메시지는 두 번째 설명이다: 예) unknown field "path"; did you mean "cwd"?
- default 값은 하네스가 채운다 (모델이 지킨다고 가정하지 않음)
- provider별 방언 변환: oneOf, $ref, additionalProperties 등 지원 범위가 다르다. 변환 불가 시 해당 도구는 노출하지 않고 로그에 경고
- strict 모드는 지원 provider에서 선택적으로 켠다

## 실행기

- 동기 실행이 기본. 기본 타임아웃 120초
- 타임아웃 시 지금까지의 출력과 still running을 반환하고, 이어서 확인하는 방법을 결과에 적는다
- 긴 작업은 시작/관찰 분리: 작업 ID 반환, 별도 도구로 출력 조회 및 종료
- 병렬: 읽기 전용 도구만 동시 실행
- 취소: AbortSignal에 해당하는 취소 토큰을 ExecCtx로 전달
- 환경 고정: 작업 디렉터리, 환경 변수, 셸 종류

## 결과 처리

- 절단 상한 기본 20,000자. 형식: [truncated, N more lines]. 앞부분/앞뒤 보존은 도구별로 정함
- 경로는 작업 디렉터리 기준 상대경로, 줄 번호는 항상 부여
- 바이너리는 요약 또는 파일 경로로 대체
- 이미지는 이미지 블록으로 반환
- 오류는 is_error=true + 사람이 읽을 수 있는 원인
- 빈 결과 금지: 최소 ok 또는 완료 요약
- 모든 실패 경로(미등록 도구, 검증 실패, 거부, 예외, 타임아웃)는 결과 문자열로 반환

## 실행 순서 (executeCall)

1. 이름으로 조회, 없으면 unknown tool 오류
2. 스키마 검증
3. 권한 판단 (allow / ask / deny)
4. 타임아웃과 취소 토큰을 걸고 실행
5. 절단, 빈 결과 보정
6. 세션 로그 기록

## 하네스가 지원하지 못하는 것 (명시)

- 대화형 TTY 프로그램: 비대화형 플래그를 강제하거나 거부
- 영속 상태 세션(REPL, DB 셸): 별도 래퍼 도구가 필요 (후속)
- GUI: 지원하지 않음
- 사람 입력이 필요한 흐름(OAuth, 2FA): MCP 엘리시테이션 경로로만 (후속)
- 거대 출력/바이너리: 요약 또는 경로 래퍼
