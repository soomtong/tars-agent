# 도구 시스템 (호스트 함수)

CodeAct에서 도구는 호스트가 Cyber에 열어 준 함수다. 모델이 도구에 대해 아는 것은 시스템 프롬프트의 사양과 실행 결과뿐이므로, 사양과 오류 메시지가 품질을 정한다.

## 도구의 생애

정의(Cyber 선언 + 사양 주석) - 선택(모델이 스크립트에서 호출) - 실행(호스트 함수 본체가 검증, 권한, 실행) - 결과(반환값 또는 Cyber 오류).

## 정의

- 선언: host/prelude.cy에 #[bind] fn 선언을 둔다. 반환 타입은 !T 로 하여 실패를 값으로 돌려준다.
- 사양: 선언 위의 주석을 시스템 프롬프트에 그대로 넣는다. 구성은 (1) 한 문장 요약 (2) 언제 쓰고 쓰지 않는지 (3) 결과 모양과 상한 (4) 전제와 부작용 (5) 호출 예 한두 줄.
- 속성 주석: 읽기 전용, 파괴적 여부를 호스트 쪽 표에 둔다. 권한 분류의 1차 기준이다.
- 이름은 짧은 동사형. 외부(MCP) 도구는 mcp 네임스페이스 아래에 둔다.
- 사양 전체가 매 모델 호출에 실리므로 토큰 예산을 둔다. 자주 안 쓰는 함수는 검색 함수로 사양을 조회하는 지연 로딩을 쓴다 (06).

## 레지스트리

- 호스트 함수 표: 이름, 선언, 사양, 분류(읽기/파괴), 본체
- 출처: 내장, 플러그인, MCP
- 세션 시작 시 로더가 표에서 허용된 함수만 모듈로 노출한다. 모드(계획 모드 = 읽기 전용만)에 따라 노출 집합이 달라진다.
- 라이브러리 기본 로더는 core, meta, math, cy, c, io, test 일곱 모듈만 안다. 이 외의 이름은 로드 실패가 된다.

## 인자 검증

- 정적 타입이 1차 검증이다. 타입 오류는 cl_vm_validate 단계에서 컴파일 오류로 돌아간다.
- 값 검증(경로 범위, 정규식 문법, 크기)은 호스트 함수 본체가 하고 오류 메시지로 가르친다. 예: unknown option "path"; did you mean "cwd"?
- 기본값은 호스트 함수가 채운다.

## 호스트 함수 작성 규칙

- 값으로 받은 매개변수(str, []T, 관리 필드를 가진 구조체)는 호스트가 소유한다. 다 쓰면 cl_str_deinit, cl_slice_deinit 등으로 해제한다. 빌리기만 하려면 [&]T 로 선언한다.
- 모든 실패 경로는 오류 값으로 반환한다. Zig @panic이나 abort로 프로세스를 죽이지 않는다.
- 오래 걸릴 수 있는 함수는 자체 시간 제한과 취소 플래그 확인을 가진다 (cl_vm_interrupt는 호스트 함수 안에서 막힌 호출을 못 끊는다).
- 출력이 크면 호스트 함수 안에서 상한으로 자르고 [truncated, N more lines]를 붙인다.
- 경로는 작업 디렉터리 기준 상대경로, 줄 번호는 항상 부여한다. 바이너리는 요약으로 대체한다.
- 부작용만 있는 함수도 완료 요약을 돌려준다 (빈 결과 금지).

## 실행기 (프로세스 시작과 관찰 분리)

- 셸 같은 긴 작업은 시작 함수가 작업 ID를 돌려주고 관찰 함수로 출력을 조회, 종료한다. 종료 대상은 하네스가 시작한 작업으로 한정한다.
- 타임아웃 시 지금까지의 출력과 still running을 돌려주고, 이어서 조회하는 방법을 결과에 적는다.
- 환경 고정: 작업 디렉터리, 환경 변수, 셸 종류.
- 병렬은 스크립트가 spawn으로 표현하되 초기에는 막는다. 비-main await 경로가 아직 TODO이고 Zig @panic으로 프로세스를 죽일 수 있기 때문이다.

## 결과 처리

- 실행 결과 = 출력 + 마지막 표현식 값 + 오류 요약. 상한 기본 20,000자, 절단 표시 필수
- 이미지가 필요하면 별도 호스트 함수가 이미지 블록을 만들어 tool_result에 첨부한다 (후속)
- 오류는 is_error=true 와 읽을 수 있는 원인

## 표준 라이브러리 공백

Cyber에는 JSON, 정규식, 날짜 라이브러리가 없다. 호스트 함수로 제공한다 (json 파싱/직렬화, regex 검색, 시각). 구현은 Zig 쪽에서 하고 선언만 Cyber에 둔다.

## 하네스가 지원하지 못하는 것

- 대화형 TTY 프로그램: stdin을 닫고 비대화형으로 강제하거나 거부
- 영속 상태 외부 세션(DB 셸): 별도 래퍼 필요 (후속)
- GUI: 지원하지 않음
- 사람 입력이 필요한 흐름(OAuth): MCP 엘리시테이션 경로 (후속)
- 거대 출력과 바이너리: 요약 또는 경로
