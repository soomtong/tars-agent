# 0013 범위: 코딩 에이전트와 tars 자기 조작

상태: 사용자 지시 (2026-11-12)

## 결정

- tars-agent는 코딩 에이전트다. 범용 터미널 에이전트로 넓히지 않는다.
- tars 시스템 안에서의 컴퓨터 사용(computer use)을 범위에 둔다. 크기는 자기 조작(self operation) 정도다: 터미널에서 명령을 실행하고 콘솔에 입력한다.
- 이를 위해 tars-linux의 내부 구조를 바꿔야 하면 그 개선 작업도 이 프로젝트에 포함한다. cyber에서 한 것처럼 필요한 것은 직접 만든다.

## 바뀌는 것

- ADR 0009의 "tars.* 능력" 행: 되살리는 조건이 "tars-linux에서 제어 채널 설계"였다. 이제 그 설계가 이 프로젝트의 일이다. 모의 구현을 만들지 않는다는 판단은 그대로다.
- tars-linux는 읽기만 하던 이웃에서 함께 고치는 대상으로 바뀐다.

## 진행 방식 (Claude의 해석, 사용자가 바꿀 수 있다)

- cyber와 같은 흐름을 기본으로 한다: 필요의 증거와 함께 요청서(docs/requests/tars-linux-*.md)를 쓰고, tars-linux 저장소에서 그 저장소의 절차(design doc, plan, 게이트)로 만든다.
- 이 세션이 tars-linux를 직접 편집하는 것은 사용자가 지시할 때다.

## 아직 정하지 않은 것

- 자기 조작의 정확한 표면: 다른 패널에 입력 보내기, 패널 화면 읽기, 패널 만들기와 닫기 중 어디까지인지
- 제어 채널의 모양과 agentd(ADR 0004)가 필요한지
