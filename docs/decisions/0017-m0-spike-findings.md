# 0017 M0 스파이크의 발견과 본체에 대한 추천

상태: 발견은 확정 (cyber 0.4.10, 2026-11-14, 실측). 추천은 확정이 아니다. 본체를 만들 때 단계마다 사용자가 정한다 (ADR 0012의 덧붙임).

상세: docs/spikes/2026-11-14-m0-spikes-review.md. cyber 요청: docs/requests/cyber-0.4.10-m0-spike-findings.md.

## 증명된 것

- Zig 0.17.1 호스트가 libcyber 0.4.10을 정적 링크해 VM을 돌린다. 검사 31개가 macOS arm64에서 통과했다. x86_64-linux-gnu 교차 빌드도 된다.
- 승인 대기를 VM 밖에서 하는 설계(0011, 0016)가 고칠 것 없이 돈다: 승인, 거부, 취소, 버린 요청, 동시 요청, 중첩 scope.
- 상한 넷이 폭주를 멈추고 VM은 계속 쓸 수 있다. 모델이 쓴 무한 루프도 멈췄다.
- Zig std.http로 스트리밍 요청이 된다. curl 대안은 필요 없다.
- 0015의 방향이 맞다. 블록 넷과 thinking의 불투명 칸 하나로 두 형식, 제공자 둘, 모델 셋을 받았다.
- 0.4.10에 맞춘 안내로 CodeAct가 과제 셋을 모델 셋으로 21번 모두 끝냈다. 컴파일 오류는 작은 모델(qwen3.8-flash)에만 과제당 1.4번 있었다.

## 깨진 것 (cyber 0.4.10)

- 실패한 컴파일 뒤 다음 컴파일(검증 포함)에서 프로세스가 죽는 경로가 있다.
- `!str` 값을 복사하지 못해 `Future[!str]`을 쓸 수 없다.
- `^[]str`에 `+=`하면 검증을 통과한 스크립트가 실행 중에 호스트를 죽인다.
- 의존으로 받아도 라이브러리 아티팩트가 나오지 않는다.
- 조용히 다른 값을 내는 것: 슬라이스의 `..=`, `not a and b`의 묶임, 풀지 않은 `!int`의 출력. 안내가 피하는 법을 가르친다.

## 스파이크 안에서 Claude가 정한 것 (위임받은 결정)

- 순서: 스파이크 1, 2a, 2b, 3. 위험이 큰 호스트 경계부터 했다.
- cyber.h는 translate-c 패키지로 가져왔다. 본체의 추천은 손으로 쓴 extern이다.
- 0.4.10의 결함을 넘어 나머지를 보려고 문자열 결과는 손잡이로, 검증은 fork한 자식에서 했다.
- 모델이 쓴 명령은 샌드박스에서만 돌렸다(macOS sandbox-exec: 쓰기는 작업 폴더, 네트워크 차단, 사용자 폴더 읽기 차단, 명령당 20초).
- 안내 문서(prompt/cyber-subset*.md)를 0.4.10 기준으로 다시 썼다. 0.4.10에 없는 문법을 빼고, 0.4.10의 함정을 피하는 법(목록은 `[]T{}`, 정렬은 struct 목록, 문자열 순서는 `less`, 목록에 `^` 금지)을 넣었다.
- 스파이크 코드는 spike/에 커밋해 두었다. 검토가 끝나면 지운다.

## 본체에 대한 추천

검토 문서 9절의 열여섯 항목이다. 구조에 닿는 것만 여기 옮긴다.

1. 명세 01의 구성요소와 경계는 그대로 간다.
2. 능력은 모두 `Future[!T]`를 돌려주고 머리말 래퍼가 await한다. 승인이 필요 없으면 호스트 함수 안에서 바로 완료한다.
3. 검증은 세션 VM에서 바로 한다. 스크립트 실행이 호스트를 죽이는 길이 남아 있는 동안, runtime 경계를 같은 프로세스로 둘지 실행만 별도 프로세스로 둘지 본체 첫 단계에서 정한다.
4. 호스트 로더는 허용 목록이다. 능력 함수는 메인 스레드가 아니면 panic을 돌려준다.
5. 프로세스 실행 능력은 자체 시간 상한, 표준 입력 차단, 출력 상한, 취소를 가진다. VM의 타이머는 승인 뒤 루프가 돌리는 프로세스에 닿지 않는다.
6. 읽기 능력도 권한의 대상이다. 읽은 것은 모두 모델 제공자에게 간다.
7. (2026-11-13 사용자 지시) 결함은 모두 고치고 진행한다. 검증을 자식 프로세스에서 하는 우회와 손잡이 우회는 본체에 넣지 않는다. cyber의 수정 릴리스가 본체 첫 단계의 선행 조건이다 (feedback-fix-spike-defects-first.md).
8. 안내 문서의 예제와 조언은 세션 VM에서 확인한다. 예제는 모델이 그대로 넓혀 써도 안전한 것으로 고른다.
9. direct 모드는 대조군이면서 작은 모델용 기본값 후보다.
