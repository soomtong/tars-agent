상태: 확정 (2026-11-10). 정규식과 JSON 행은 같은 날 0010이 바꿨다. "만들 수 있음"을 기준으로 걸렀다. 뺀 것은 필요가 드러나면 되살린다.

| 뺀 것 | 이유 | 되살리는 조건 |
|---|---|---|
| 방식 B(순수 Cyber CLI) 스파이크 | 방식 A가 확정됐고, B는 중단, 연료, 샌드박스가 없어 증명하는 것이 제품과 다르다 | 없음 |
| docs/design.md, docs/fork-plan.md | spec/ 과 08 문서가 같은 내용이다. 같은 것을 두 곳에 쓰면 어긋난다 | 없음 |
| 다중 세션 데몬 agentd | 0004 | tars 제어 채널, MCP 서버 방향 |
| tars.* 능력과 모의 구현 | tars 터미널에 외부 제어 채널이 없다. 상대가 없는 모의는 검증하는 것이 없다 | tars-linux에서 제어 채널 설계 |
| 셸 명령 분류기 | 0007 | 없음 |
| 정규식, JSON을 호스트 능력으로 주기 | 0010이 바꿨다. cyber 표준 모듈로 만든다 | 없음 |
| 스크립트의 spawn | 연료가 스레드마다 따로 세어지고 승인 프롬프트가 겹친다 | 호스트 쪽 병렬 읽기 능력으로 대신 |

| MCP, 서브에이전트, 훅, 스킬 | v1의 구조 위에 얹히는 확장이다 | M6 |
