# 0020 문서는 지금의 상태만 적는다

상태: 사용자 지시 (2026-11-14). "구버전 테스트 기록과 결과, 그리고 구버전 dev에서 발생한 내용들을 모두 무시하고 현재 버전에 맞는 문서로 재작성", "과거 버그나 과거 기록이 LLM 컨텍스트를 오염하지 않도록".

## 결정

저장소의 문서(명세, 결정, 검토, 요청서, 안내, HANDOFF, TODO)는 기준 빌드에서 지금 참인 것만 적는다. 고쳐진 결함, 걷어 낸 우회, 옛 버전에서의 동작, 버전별 변천("0.4.x부터", "0.4.y에서 바뀌었다")은 적지 않는다. 그것은 git 이력에 있다.

## 근거

이 저장소의 문서는 다음 세션의 에이전트가 읽고 판단하는 자료다. 옛 결함과 우회가 문서에 남아 있으면 이미 닫힌 문제를 피하는 코드를 쓰거나, 지금은 되는 모양을 쓰지 않게 된다. 사람에게도 지금의 사실과 지나간 사실을 가르는 일이 짐이다.

## 적용

- 기준 빌드가 바뀌면 문서를 고쳐 쓰지, 덧붙이지 않는다. 바뀐 항목은 새 동작으로 바꾸고 기준 버전 줄을 갱신한다.
- 결정 문서(ADR)의 결정, 근거, 버린 대안은 남긴다. 근거가 옛 동작에 기댔다면 지금 동작으로 다시 쓴다.
- 반영이 끝난 요청서와 보고서는 지운다. 열린 요청만 docs/requests에 둔다.
- 스파이크 산출물도 같다. 옛 회차의 원자료와 재현 파일은 지우고 기준 빌드의 회차만 둔다.
- 사실의 출처가 실측이면 기준 빌드에서 다시 잰 것만 적는다. 다시 재지 못한 것은 "확인하지 않았다"로 적는다.
