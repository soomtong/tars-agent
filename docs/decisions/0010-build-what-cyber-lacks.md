# 0010 Cyber에 없는 것은 Cyber에 만든다

상태: 확정 (2026-11-10, 사용자 지시 "we will build missing features of cyber lang, like std stuffs. things we need, we make."). 0009의 정규식, JsonValue 행과 spec/04의 json 능력을 바꾼다.

## 결정

에이전트가 필요로 하는데 Cyber에 없는 언어 기능과 표준 라이브러리는 soomtong/cyber에 만든다. 호스트 능력으로 돌려 막거나 범위에서 빼지 않는다.

가르는 기준은 하나다. 세계에 닿는가.

- 닿지 않는 것(순수 계산)은 Cyber 표준 모듈이다: JSON, 정규식, 날짜와 시간 계산, 문자열과 컬렉션 보강, 경로 문자열 다루기.
- 닿는 것(파일, 프로세스, 네트워크, 시계 읽기, 사용자)은 능력이다. 권한 게이트와 감사 기록을 지나야 하기 때문이다.

## 근거

- fork의 용도가 둘이다: 평소 쓰는 스크립트 언어와 에이전트의 실행 언어. JSON과 정규식이 없는 스크립트 언어는 어느 쪽으로도 모자라다. 표준 모듈로 만들면 CLI와 에이전트가 함께 얻는다.
- 능력으로 돌려 막으면 모양이 나빠진다. json.get(text, path)는 호스트가 값 타입을 못 주어 생긴 우회였다. 모델은 다른 언어에서 익힌 json.parse와 값 트리를 기대하고, 기대와 다른 표면은 오류율로 돌아온다.
- 순수 계산이 게이트와 감사 기록을 지나면 기록이 소음으로 찬다.
- upstream이 멈췄으므로 기다릴 상대가 없다. fork가 유일한 유지 주체다.

## 범위를 정하는 법

"필요한 것"만 만든다. 필요의 증거는 둘 중 하나다: 평가 과제(eval/)나 실제 세션에서 드러난 실패 유형, 또는 스파이크에서 막힌 지점. 목록은 spec/08의 "cyber에서 만들 것"에 모으고 거기서 순서를 정한다.

처음부터 필요가 분명한 것: json, regex, time 표준 모듈과 임베딩용 변경(의존으로 쓰는 빌드 내보내기, 모듈 허용 표, spawn 차단).

## 조건

- 표준 모듈은 신뢰하지 않는 스크립트가 부른다. 입력 크기에 대해 시간과 메모리가 예측 가능해야 한다. 정규식은 역추적 없는 엔진(선형 시간)으로 만든다. 모든 할당은 VM의 메모리 상한 아래에 있고 긴 루프는 연료 검사점을 지난다.
- 구현 언어는 모듈마다 정한다. Zig 바인딩(Zig std.json 재사용 등)이든 Cyber 소스든 라이브러리 로더와 CLI 양쪽에서 같은 이름으로 실린다.
- 의존 규칙(BSD 호환, GPL 계열 금지)은 cyber에 더하는 것에도 적용한다. 정규식 엔진은 직접 쓴다.
- 런타임은 여전히 soomtong/cyber 한 곳이다 (0005). tars-agent는 태그와 해시로 고정해 올린다.
- cyber에 더한 것은 그 저장소의 절차(테스트, 발견 이슈 기록, 릴리스 노트)를 따른다.

## 결과

- 시스템 프롬프트의 Cyber 안내가 json, regex, time 모듈을 가르친다. 4,000 토큰 예산은 그대로다.
