## 2. 읽는 법

상태는 넷이다.

| 상태 | 뜻 | 반영된 곳 칸 |
|---|---|---|
| 채택 | 결정이나 명세의 규칙이 됐다 | ADR과 명세 절 |
| 다시 봄 | 그 단계에서 다시 보기로 했다 | ADR과 TODO 단계 |
| 버림 | 가져오지 않기로 했다 | 이유 |
| 추적 없음 | ADR, 명세, TODO 어디에도 없다 | 비어 있다 |

- 명세 절은 "문서 번호 절 이름"으로 적는다(예: 07 줄 머리).
- ADR 0017의 추천은 "본체를 만들 때 단계마다 사용자가 정한다"는 상태다. 명세가 규칙으로 적은 것은 채택으로 셌다.
- "이미 같음"은 다른 경로로 같은 결론에 닿은 것이다. 채택으로 센다.
